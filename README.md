# ChemQuest2

ChemQuest2 is a Godot 4 chemistry learning game. It combines a story-driven hometown hub, quest progression, a glossary, achievements, and several interactive minigames that teach elements, compounds, mixtures, accuracy and precision, density, and states of matter.

## Project Info

- Engine: Godot 4.6
- Main scene: `intro.tscn`
- Main menu scene: `games/main.tscn`
- Target: desktop preview and Android export
- Render mode: Mobile renderer
- Default viewport: `1280x720`

## Getting Started

To play the game, check the repository's GitHub Releases page and install the latest APK on an Android device.

For development:

1. Install Godot 4.6 or newer.
2. Open the project folder in Godot.
3. Run the project from `project.godot`.
4. Press `START` on the intro screen to enter the main menu.

The project uses Godot's `user://` storage for save data. Existing local saves may continue from the last saved scene, while New Game resets quest and save progress.

## Controls

- Move: `WASD`
- Interact: `F`
- Jump: `Space`
- Drop: `Q`

Touch input is enabled through mouse-to-touch emulation and mobile-oriented settings.

## Project Structure

```text
assets/                         Shared fonts, UI, character, and environment assets
games/main.tscn                 Main menu
games/global/                   Autoload managers and shared game data
games/global/music/             Music and sound effect assets
games/achievements/             Achievement and reward scenes
games/glossary/                 In-game element glossary
games/chapter_one/              Chapter One content
games/chapter_one/hometown/     Hub area, NPCs, panels, map, and building entries
```

## Main Systems

- `QuestManager` loads quest templates from `games/global/quest.json`, tracks active quests, and emits quest update signals.
- `SaveManager` stores current scene, spawn point, quest progress, and shown feedback in `user://save.json`.
- `SpawnManager` keeps player spawn transitions consistent between scenes.
- `DialogueManager` loads dialogue lines for NPC interactions.
- `MusicManager` centralizes background music and sound effects.
- `FadeManager` handles scene transitions.
- `GuideManager` and `PlayerFeedbackManager` track tutorial and feedback state.

## Chapter One Content

Chapter One starts in the hometown hub and branches into lesson areas:

- Building One: element lessons, compounds, mixtures, separation methods, and accuracy vs precision.
- Building Two: density challenges and states of matter platforming/minigame sections.
- Glossary: element information screens and supporting data.
- Achievements: reward and progress scenes tied to quest completion.

## Data Files

- `games/global/quest.json` contains quest definitions and default progression state.
- `games/global/player_feedback.json` contains feedback text shown during progression.
- `games/glossary/data/` and `glossary/data/` contain element information.
- `.import` files are generated by Godot and should stay with their source assets when assets are tracked.

## Exporting

The repository includes an Android export preset in `export_presets.cfg`. The preset is configured for Android with `arm64-v8a` enabled and an output path of `../chemquest_beta3.1.apk`.

Before exporting, make sure Android export templates and signing settings are configured in your local Godot installation.

## Version Control Notes

Ignored local/generated folders:

- `.godot/`
- `/android/`
- `.vscode/`

Do not commit Godot cache files or local editor settings. Keep source scenes, scripts, assets, and import metadata tracked.
